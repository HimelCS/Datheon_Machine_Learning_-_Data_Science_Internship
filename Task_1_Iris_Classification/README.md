# Task 1: Iris Flower Classification

## Project Overview
This project implements supervised machine learning classification using the Iris dataset.

## Dataset
Source: [Iris Dataset](https://raw.githubusercontent.com/mwaskom/seaborn-data/master/iris.csv)

The dataset contains 150 samples, four numerical features, and three flower species.

## Algorithms
- Logistic Regression
- Decision Tree Classifier

## Data Preprocessing
- Exploratory Data Analysis (EDA)
- Feature Scaling using StandardScaler
- Train-Test Split (80:20)

## Evaluation Metrics
- Accuracy
- Precision
- Recall
- F1-Score
- Confusion Matrix

## Visualization
- Seaborn Pairplot
- Correlation Heatmap
- Confusion Matrix
- Decision Boundary

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## How to Run
Open `Iris_Classification.ipynb` using Google Colab or Jupyter Notebook and run all cells.

## Objective
To compare Logistic Regression and Decision Tree classifiers and evaluate their classification performance.
